# Цифровой блокнот стоматолога — Инструкция по запуску и передаче

Этот проект полностью автономный: база данных (SQLite с изоляцией RLS) и загруженные снимки хранятся прямо внутри папки `data/`. Никаких сторонних СУБД устанавливать не нужно.

---

## 1. Что нужно установить на новом компьютере (только 1 раз)

На компьютере должен быть установлен **Node.js (версия 22.5 или новее, рекомендуется Node.js 22 LTS или 24)**:
- Скачать с официального сайта: [https://nodejs.org/](https://nodejs.org/)
- При установке просто нажимайте «Next» (все галочки по умолчанию).

---

## 2. Как запустить приложение

### Вариант А — Быстрый запуск в 1 клик (Windows)
1. Откройте папку проекта `dental-notebook`.
2. Дважды нажмите на файл **`ЗАПУСК.bat`**.
3. Скрипт сам проверит наличие библиотек (`node_modules`), при первом запуске автоматически установит их, запустит сервер и откроет браузер по адресу:
   **http://localhost:3001**

> Не закрывайте чёрное окно консоли, пока работаете в блокноте. Чтобы остановить программу — просто закройте окно консоли или нажмите `Ctrl + C`.

---

### Вариант Б — Запуск через Терминал / PowerShell / VS Code (Windows, macOS, Linux)

1. Откройте терминал в папке `dental-notebook`.
2. При **первом запуске** установите зависимости:
   ```bash
   npm install
   ```
3. Запустите приложение:
   ```bash
   npm run dev
   ```
4. Откройте в браузере:
   **http://localhost:3001**

---

## 3. Как правильно отправить проект другому человеку (в ZIP-архиве)

### Что НЕ нужно добавлять в архив:
- Папку **`node_modules`** можно **удалить перед архивацией** (она весит много и автоматически установится на другом компьютере командой `npm install` или через `ЗАПУСК.bat`). Без неё архив весит меньше 1 МБ.

### Где хранятся все данные (пациенты, приёмы, расписание, склад, снимки):
Все данные лежат в папке **`data/`**:
- `data/clinic_public.sqlite` — все пациенты, приёмы, расписание, финансы, склад и прайс-лист.
- `data/clinic_auth_internal.sqlite` — настройки входа и сессии клиники.
- `data/private_uploads/` — прикреплённые рентген-снимки и фото.
- `data/backups/` — зашифрованные резервные копии.

**Выберите нужный сценарий при отправке:**
1. **Если нужно передать проект ВМЕСТЕ с вашей базой пациентов:**
   Оставьте папку `data/` внутри архива. У получателя откроются все ваши пациенты, записи и история.
2. **Если нужно передать ЧИСТЫЙ блокнот (для другого врача с нуля):**
   Удалите папку `data/` перед отправкой архива. При первом запуске программа автоматически создаст новую чистую базу данных.

## 4. Дополнительные команды (для разработчика)

- `npm run dev` — запуск приложения (сервер + интерфейс на `http://localhost:3001`)
- `npm run build` — сборка фронтенда для продакшена (`dist/client`)
- `npm run typecheck` — проверка типов TypeScript
- `npm test` — запуск 8 автоматических тестов безопасности (выполняются в изолированной памяти `:memory:`, не затрагивая рабочую базу `data/`)
